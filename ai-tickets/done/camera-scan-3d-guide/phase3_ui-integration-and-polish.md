# Phase 3: UI Integration and Polish

## 문제/목표
3D 애니메이션 가이드가 추가되었으므로 기존의 장황한 텍스트 가이드를 간소화하고, 스캔 진행 상황을 시각적으로 더 잘 보여주기 위해 3D 큐브의 시각 효과를 다듬습니다.

## 수정 대상 파일과 위치
- `app/src/main/assets/js/scan/scan-ui.js`
- `app/src/main/assets/index.html`

## 구체적인 구현 방향
1. 기존의 `"파랑 면(B)이 위로 오게 들어주세요"` 같은 텍스트 안내를 좀 더 짧게 줄이거나, 3D 큐브가 있으므로 보조 수단으로만 배치합니다.
2. 미니 큐브 머티리얼 폴리싱:
   - 현재 촬영해야 하는 면(목표 면)은 밝고 선명하게 표시 (예: 테두리 하이라이트).
   - 이미 촬영을 완료한 면은 반투명하게 처리하여 진행 상황을 인지할 수 있게 함.
3. 모바일 화면에서 카메라 프리뷰와 스캔 격자를 가리지 않도록 3D 가이드의 위치와 크기를 최적화합니다.

## 검증 방법
전체 스캔 플로우를 테스트하면서, 텍스트 가이드와 3D 가이드가 조화롭게 보이며, 기촬영된 면과 촬영할 면이 시각적으로 명확히 구분되는지 확인합니다.
