# Phase 2: Implement Rotation Animation

## 문제/목표
현재 스캔 단계(U -> R -> F -> D -> L -> B)가 바뀔 때마다, 미니 3D 큐브가 사용자가 큐브를 돌려야 하는 방향으로 애니메이션되며 회전하도록 만듭니다.

## 수정 대상 파일과 위치
- `app/src/main/assets/js/scan/scan-ui.js`

## 구체적인 구현 방향
1. `SCAN_FACE_GUIDE` 배열에 각 단계별로 목표로 하는 3D 회전값(Quaternion 또는 Euler angle)을 매핑합니다.
2. `renderScanStep()` 함수가 호출되어 다음 스캔 면으로 넘어갈 때, 미니 큐브의 현재 회전값에서 목표 회전값으로 부드럽게 전환되도록 애니메이션(예: requestAnimationFrame를 이용한 보간 또는 기존에 포함된 Tween 라이브러리 사용)을 구현합니다.
3. 애니메이션 중에는 사용자가 큐브가 어느 방향으로 도는지 확실히 인지할 수 있도록 속도를 적절히(약 0.5초~1초) 조절합니다.

## 검증 방법
스캔을 진행하면서 각 면을 촬영 완료하고 다음 단계로 넘어갈 때, 화면 안의 미니 큐브가 올바른 방향(예: 파란 면이 위로, 흰색 면이 정면으로)을 향해 부드럽게 회전하는지 확인합니다.
