# Phase 2 — 메인 화면 재배치 (컨트롤 레일·큐브 중앙화)

> 상태: **완료**
> 선행: Phase 1

## 문제/목표

`≥600px`에서 메인 화면(오버레이가 아닌 기본 화면)을 태블릿답게 재배치한다. 핵심은
**하단 풀폭 컨트롤 카드를 측면 레일로 옮기고, 큐브 캔버스에 중앙 넓은 공간을 주는 것**이다.

## 수정 대상

- `app/src/main/assets/css/cube.css`
  - `#ui`(현재 `bottom; left/right 14px+safe` 풀폭 카드, `cube.css:92`)
  - `.ui-row` / `#btn-undo`·`#btn-redo`·`#btn-shuffle`·`#btn-solve`·`#btn-scan`
  - `#top-bar`(`cube.css:11`), `#btn-theme`(`cube.css:38`), `#btn-stats`

## 구현 방향 (`≥600px` 블록 안에서만)

1. **컨트롤 패널 → 사이드 레일.** `#ui`를 화면 폭 전체로 늘리지 말고
   한쪽(예: 우하단 고정 폭 `--ui-rail-width`) 카드로 만든다. 버튼이 과도하게 커지지 않도록
   `flex: 1`로 늘어나던 버튼에 상한을 준다. `.ui-row`는 유지하되 폭이 레일 기준이 되게 한다.
   - 대안: 세로 레일(버튼 세로 스택). 실제 배치는 스크린샷 보고 택1. 결정 근거를 진행 기록에 남긴다.
2. **큐브 중앙 공간.** 큐브 캔버스는 3D 씬이 채우므로 DOM 변경 없이, 컨트롤이 한쪽으로
   빠지며 자연히 중앙 공간이 넓어진다. 컨트롤 레일이 캔버스 터치를 가리지 않는지 확인
   (레일 영역 밖은 큐브 회전이 정상 동작해야 함).
3. **상단바/아이콘 정렬.** `#top-bar`(타이머/무브)와 `#btn-theme`·`#btn-stats`가 넓은 화면에서
   허전하지 않게 간격·크기를 조정. 아이콘이 너무 작아 보이면 태블릿에서 살짝 키운다.
4. **인셋 준수.** 모든 새 위치가 `var(--safe-*)`를 포함하도록 유지.

## 주의

- 큐브 터치 회전(`touch.js`, `layer-rotation.js`)은 화면 좌표 기반이다. 컨트롤 레일이 캔버스
  위에 겹치면 그 영역의 제스처가 막힌다. 레일을 캔버스 밖 영역에 두거나, 겹침을 최소화한다.
- JS는 수정하지 않는다. 배치만 CSS로 바꾼다.

## 검증

- `≥600px` 세로/가로: 컨트롤이 풀폭으로 늘어나지 않고 레일로 표시, 버튼 크기 적정.
- 큐브 회전·레이어 드래그가 컨트롤 영역 밖에서 정상 동작.
- `<600px` 폰 회귀 0.
- `./gradlew lint` 통과, `npm test` 통과.

## 진행 기록

- 2026-08-02: `cube.css` `@media (min-width: 600px)` 블록에 재배치 규칙 추가.
  - `#top-bar`: 중앙 → 좌상단(`left: 20px+safe`, `transform: none`).
  - `#btn-stats`: 좌상단 → 우상단 테마 아이콘 옆(`right: 62px+safe`). 원래 통계가 좌상단이라
    타이머(좌상단)와 겹쳐서 우측 클러스터로 이동해 프리뷰(🌙📊 우측)와 일치시킴.
  - `#ui`: 좌우 풀폭 카드 → 우하단 고정폭 레일(`width: var(--ui-rail-width)=280px`,
    `right: 20px+safe`, `bottom: 24px+safe`, `left: auto`). 기존 `.ui-row` 구조(2·2·1 버튼
    배치)는 유지 — 레일 폭 안에서 자연스러워 별도 세로 스택 불필요.
  - 레일이 우하단 구석에만 있어 큐브 캔버스 중앙/좌측 터치 회전 영역을 가리지 않음.
- **실기기 검증(에뮬레이터)**: Pixel 급 에뮬레이터를 2560x1600·density 240(≈1707dp 폭)으로
  강제해 태블릿 레이아웃 확인 — 컨트롤 우하단 레일, Moves 좌상단, 아이콘 우상단, 큐브 중앙
  정상. 이후 1080x2400·density 420(≈411dp)으로 원복해 **폰 레이아웃 무회귀 확인**.
- 폰/태블릿 모두 스크린샷으로 확인. 실제 태블릿 AVD(sw720 등) 및 다크모드는 Phase 4에서 재확인.
