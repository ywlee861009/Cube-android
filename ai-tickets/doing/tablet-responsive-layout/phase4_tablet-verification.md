# Phase 4 — 태블릿·폰 회귀 검증

> 상태: 미착수
> 선행: Phase 2, Phase 3
> 검증 주체: 에뮬레이터/실기기 매트릭스

## 문제/목표

재배치가 실제 기기에서 의도대로 보이고, 폰에 회귀가 없음을 확인한다. 기능을 추가하지 않는다.
측정하고, 깨진 조합을 메운다.

## 검증 매트릭스

### 화면 크기 (에뮬레이터로 충분)

| 조건 | 기대 |
| --- | --- |
| 폰 `<600px` 세로 | 기존 레이아웃 그대로(회귀 0) |
| 폰 `<600px` 가로 | 기존 landscape 동작 유지 |
| 큰 폰 가로(폭 ≥600px) | 넓은 레이아웃 적용, 깨짐 없음 |
| 태블릿 sw600 세로/가로 | 컨트롤 레일·중앙 다이얼로그 정상 |
| 태블릿 sw720 세로/가로 | 여백 과다·요소 고립 없이 정돈 |

### 회전 (configChanges 적용 상태)

- 스캔 도중을 포함해 회전 시 재생성 없이 레이아웃이 즉시 재대응하는지.
- 회전 순간 컨트롤 레일·오버레이가 잘리거나 겹치지 않는지.

## 점검 항목

- 컨트롤 버튼 크기·간격이 태블릿에서 과대/과소하지 않음
- 큐브 캔버스 터치 회전이 컨트롤 레일 영역 밖에서 정상
- 오버레이(완성/통계/스캔리뷰)가 중앙 적정 폭, 내부 스크롤·클릭 정상
- 스캔 오버레이(`orientation: landscape` 쿼리와의 조합) 가로 태블릿에서 정상
- `--safe-*` 인셋 준수(컷아웃/시스템바 침범 없음)
- 다크 모드에서도 동일하게 정상

## 릴리스 게이트

- 폰 `<600px` 세로/가로 회귀 **0건**
- 태블릿 sw600/sw720에서 컨트롤 풀폭 늘어남·오버레이 풀블리드 **0건**
- `./gradlew lint` 신규 경고 없음, `npm test` 통과

### 남은 검증 (실기기 필요 — 에뮬레이터 한계)

- **스캔 리뷰 다이얼로그**: 카메라 스캔이 있어야 떠서 에뮬레이터 실사 확인 불가.
  CSS는 통계 다이얼로그와 동일 패턴이라 신뢰도 높으나 실기기 육안 확인 권장.
- **완성 오버레이**: CSS 무변경(원래 중앙 정렬)이라 회귀 위험 낮음. 태블릿 실기기에서
  솔브 완료 시 중앙 표시만 최종 확인.
- **실제 태블릿 AVD/기기**: 이번엔 `wm size` 대리 검증. 진짜 태블릿의 density·종횡비에서
  최종 확인 권장(Pixel_Tablet_33 AVD 부팅이 반복 실패해 폰 에뮬레이터로 대체함).
- **물리적 회전(configChanges)**: 여러 폭을 강제해 반응형 CSS 재대응은 확인. 실기기에서
  실제 회전 제스처 시 재생성 없이 즉시 재배치되는지 최종 확인.
