# 티켓: 태블릿(≥600px) 반응형 레이아웃

> 상태: **미착수**. 폰 전용으로 짜인 현재 UI를 넓은 화면에서 재배치한다.
> 최대 리스크는 폰 레이아웃 회귀와 오버레이(스캔/통계) 겹침이다.

## 목적과 배경

현재 UI는 폰 세로를 전제로 한다. `cube.html`(193줄) + `cube.css`(698줄)에 미디어쿼리는
`@media (orientation: landscape)`(스캔 오버레이용) **하나뿐**이고, 태블릿 브레이크포인트가 없다.

그 결과 태블릿·큰 화면에서:

- 하단 `#ui` 컨트롤 카드가 화면 폭 전체(`left/right: 14px`)로 늘어나 버튼이 과도하게 커진다.
- 상단바·테마/통계 아이콘이 넓은 화면 상단에 외롭게 흩어진다.
- 오버레이(`#solved-overlay`, `#stats-overlay`, `#scan-review-overlay`)가 풀폭/바텀시트라
  넓은 화면에서 허전하거나 지나치게 커진다.

목표는 **`≥600px`에서 같은 컴포넌트를 극적으로 재배치**해 태블릿 전용처럼 보이게 하는 것이다.

### 아키텍처 결정 (확정)

**별도 UI를 포크하지 않는다. 같은 DOM·같은 JS 핸들러를 CSS로 재배치한다.**

- 핵심 상호작용(3D 큐브 캔버스 + 터치 회전)은 화면 크기와 무관하게 동일하므로 손대지 않는다.
- 달라지는 것은 "크롬"(컨트롤 패널, 상단바, 오버레이 카드)의 **배치**뿐이다.
- DOM 포크는 신규 기능을 두 벌로 유지·테스트하게 만들어 백로그 규모에서 비용이 크다.
- `configChanges`(회전 시 재생성 없음)가 적용돼 있어 CSS 브레이크포인트가 회전에 실시간
  반응한다. CSS 재배치 방식이 이 흐름과 맞물린다.

### 브레이크포인트 규약 (확정)

- 기준: `@media (min-width: 600px)` — WebView가 `width=device-width`라 CSS px ≈ dp,
  Android `sw600dp`에 대응한다.
- 이 조건은 **가로 모드의 큰 폰도 포함**한다. 이를 버그로 보지 않고, 넓은 레이아웃을
  가로 폰에도 제공하는 것으로 설계한다.
- `600px`는 시작값이다. 실기기 확인(sw600/sw720) 후 필요하면 720px 2차 단계를 추가한다.

## 스코프

- `≥600px` 브레이크포인트 도입과 넓은 화면 레이아웃 스캐폴드
- 메인 화면 재배치: 컨트롤 패널을 측면 레일로, 큐브 중앙 공간 확보, 상단바/아이콘 정렬
- 오버레이 재배치: 풀블리드/바텀시트 → 중앙 max-width 다이얼로그, 통계 그리드 열 확대
- 스캔·스캔리뷰 오버레이의 넓은 화면 배치(기존 landscape 쿼리 확장)
- 폰 레이아웃 무회귀, 가로/세로 전환 정상 동작

## 비스코프

- 3D 큐브 렌더링·터치 회전 로직 변경
- 신규 기능 추가(태블릿 전용 기능 없음 — 배치만)
- 네이티브(Kotlin) 변경 — 전부 WebView CSS 내에서 해결
- 폴더블/멀티윈도우 특수 대응(필요 시 별도 티켓)

## 전체 수용 기준

- `≥600px`에서 컨트롤 패널이 풀폭으로 늘어나지 않고 측면/정돈된 배치로 표시된다.
- 오버레이가 넓은 화면에서 중앙 정렬·적정 폭으로 표시되고 겹침·잘림이 없다.
- `<600px` 폰 레이아웃(세로/가로)에 회귀가 없다.
- 회전 시(configChanges로 재생성 없이) 레이아웃이 즉시 올바르게 재대응한다.
- `./gradlew lint` 신규 경고 없음, `npm test` 통과(JS 로직 무변경이면 그대로 통과).

## 공통 참조

### 현재 주요 레이아웃 앵커 (`cube.css`)

| 셀렉터 | 현재 배치 |
| --- | --- |
| `#top-bar` | `position: fixed; top: 16px+safe` 상단 중앙(타이머/무브) |
| `#btn-theme` | `fixed; top/right 14px+safe` 우상단 아이콘 |
| `#btn-stats` | 우상단 아이콘(테마 옆) |
| `#ui` | `fixed; bottom: 20px+safe; left/right: 14px+safe` 하단 풀폭 카드, 3 `.ui-row` |
| `#solved-overlay` / `#stats-overlay` | 모달 카드 |
| `#scan-overlay` / `#scan-review-overlay` | 스캔 UI(바텀시트형 리뷰 카드) |

### 인셋 토큰

`:root`의 `--safe-top/bottom/left/right`(네이티브가 갱신)를 모든 재배치에서 유지한다.
넓은 화면 레이아웃도 이 토큰을 존중해 컷아웃/시스템바를 침범하지 않는다.

### 기존 미디어쿼리

`@media (orientation: landscape)`(`cube.css:284`)가 스캔 오버레이 배치를 이미 바꾼다.
태블릿 쿼리와 상호작용하므로 Phase 4에서 가로 태블릿 조합을 반드시 확인한다.
